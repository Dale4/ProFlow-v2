# ProFlow Overview

ProFlow is a field work-order scheduler for window and door installation businesses.

## Purpose

Help sales, measuring, warehouse, and install crews move a job from quote to scheduled install without losing details.

## Current stack

- Backend: C# / ASP.NET Core Minimal APIs
- Frontend: React (Vite)
- Data: PostgreSQL
- Packaging: Docker
- IDE / agent workflow: Cursor

## Users (roles)

- Sales
- Scheduler
- Measure technician
- Warehouse manager
- Install manager
- Crew lead / workers

## Out of scope (for now)

- Customer-facing portal
- Full accounting / invoicing
- Native mobile app (web first)
